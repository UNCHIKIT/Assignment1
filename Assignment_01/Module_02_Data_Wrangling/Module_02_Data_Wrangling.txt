You will learn how to clean, transform, and format datasets by handling missing values, converting data types, normalizing numerical values, and creating bins for analysis. The module also introduces methods for transforming categorical variables into numerical representations suitable for modeling. Through hands-on exercises, you will apply these techniques to real-world datasets. Learning Objectives Describe the key steps in the data pre-processing pipeline when preparing a dataset for analysis Apply techniques, such as replacing or dropping missing values, using Pandas when cleaning a dataset with incomplete records Demonstrate how to convert data to the appropriate types in a scenario where formatting inconsistencies affect analysis Use normalization techniques, such as min-max scaling and Z-score transformation, to prepare numeric variables for comparison in a dataset Create bins for continuous variables using Python to simplify analysis or support categorical grouping Transform categorical variables into numerical representations using techniques like label encoding and one-hot encoding in a dataset with text-based categories Execute a full data wrangling workflow including handling missing values and formatting data on the Used Cars Pricing dataset using Pandas Apply data cleaning and transformation steps to the Laptop Pricing dataset to prepare it for further analysis Learn Video 01: Pre-processing Data in Python (2 min) Video 02: Dealing with Missing Values in Python (6 min) Video 03: Data Formatting in Python (3 min) Video 04: Data Normalization in Python (3 min) Video 05: Binning in Python (1 min) Video 06: Turning Categorical Variables into Quantitative Variables in Python (2 min) Practice Practice Quiz: Data Wrangling Lab 01: Data Wrangling -
